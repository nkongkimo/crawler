# 爬蟲基本架構

1. 入口入口 (main)
   - 啟動爬蟲流程。
   - 讀取設定、輸入網址或目標。

2. 設定管理 (config)
   - 設定待爬清單、輸出格式、重試次數、延遲時間。
   - 可用 JSON/YAML/環境變數管理。

3. 網路請求 (fetch)
   - 發送 HTTP 請求取得網頁內容。
   - 處理 headers、cookies、超時與重試。

4. 解析器 (parser)
   - 使用 BeautifulSoup、lxml 或正則表達式解析 HTML。
   - 取出標題、連結、資料欄位等。

5. 資料處理 (processor)
   - 清理資料、轉換格式。
   - 例如去除空白、合併欄位、數值轉換。

6. 儲存/輸出 (storage)
   - 將結果寫入 CSV、JSON、SQLite、MySQL 等。
   - 可依需求支援多種目標。

7. 例外處理與重試
   - 捕捉 HTTP 錯誤、解析錯誤、連線中斷。
   - 重要流程加上重試與等待。

8. 日誌與追蹤
   - 記錄爬取進度、錯誤原因。
   - 日後除錯或重新爬取時方便查。

9. 反爬與限速
   - 加入隨機等待、User-Agent 偽裝。
   - 尊重 robots.txt、避免頻繁請求。

10. 測試與維運
   - 先用小量資料測試流程。
   - 定期檢查目標網站結構是否改變。
